# Digital Worlds — Portafolio de Elian Gonzalez

Sitio estático hecho con HTML5, CSS3 y JavaScript, listo para GitHub Pages.

## Estructura
- `index.html`: página principal.
- `Assets/Css/Portafolio.css`: estilos.
- `Assets/Js/Portafolio.js`: idioma, cambio de skin, copiar correo y formulario mailto.
- `Assets/Images/`: imágenes del sitio.
- `Assets/Videos/`: coloca aquí `hero-bg.mp4` para usar un video propio en la portada. Si no existe, se usa `hero-bg.jpg`.

## Antes de publicar
1. Sustituir los placeholders de Diseño 3D por renders reales de Mictlán, Blender y Substance Painter.
2. Si se desea, sustituir `Captura-CV.png` por un CV final.
3. Agregar enlaces reales a GitHub/LinkedIn cuando estén definidos.
4. Para GitHub Pages, subir el contenido de esta carpeta a un repositorio y activar Pages desde la rama `main`.
